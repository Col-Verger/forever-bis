# runs/ — результаты прогонов WoWSims Forever

Папку заполняет `tools/run_sims.py` (локально или GitHub Action «Re-sim and deploy»);
`tools/build_data.py` склеивает её в `data.js`. Файлы коммитятся для прозрачности —
по ним всегда можно проверить, откуда каждое число на сайте.

| Файл | Что внутри |
|---|---|
| `<id>.gear.json` | финальный сет: `{slot: [itemId, enchantId, suffixId]}` |
| `<id>.guide.json` | пер-слотовый рейтинг: `{slot: {base: dps, rows: [{move, d, m}]}}`, Δ и ±95% против сета |
| `<id>.meta.json` | заголовок, метрика (DPS/HPS), значение, таленты, итерации, зерно, предупреждения |
| `<id>.settings.json` | (маг) protojson настроек — можно импортировать на wowsims.com и проверить руками |
| `<id>.status.json` | для отключённых спеков: причина (пока нет пресета в симе) |
| `<id>.link.txt` | опционально: share-ссылка WoWSims для сета, сохранённая руками один раз |
| `_summary.json` | сводка прогона |

До первого прогона папка пуста — и это честное состояние: сайт тогда показывает
«симы не прогнаны», а не выдуманные числа.
